## 🗺️ Содержание курса и структура ноутбуков

### [A.1. Нотация уравнений аналитической механики](./Asymtotic%20Methods%20in%20Astrodynamics/A.1%20Нотация%20уравнений%20аналитической%20механики.ipynb)

    Теория: Бескоординатное векторно-матричное представление фазового пространства. Соглашение о ковариантных верхних индексах для координат и контравариантных нижних индексах для импульсов. Структура составного фазового вектора.
    Практика: Реализация правил матричного дифференцирования скалярных функций по векторам и ковекторам фазовых переменных.
    Приложения: Формирование унифицированного символьного алфавита и правил дифференцирования для исключения индексного разнобоя в последующих аналитических разделах.

### [A.2. Основные понятия гамильтоновой механики](./Asymtotic%20Methods%20in%20Astrodynamics/A.2%20Основные%20понятия%20гамильтоновой%20механики.ipynb)

    Теория: Канонические уравнения Гамильтона. Первые интегралы и скобки Пуассона. Канонические преобразования. Уравнение Гамильтона-Якоби. Переменные действие-угол. Переменные Делоне и регулярные элементы Пуанкаре в небесной механике.
    Практика: Символьный расчет нелинейного сдвига частоты ангармонического маятника методом Крылова-Боголюбова на базе библиотеки SymPy. Численное моделирование фазового портрета.


### [B.1. Метод малого параметра Пуанкаре](./Asymtotic%20Methods%20in%20Astrodynamics/B.1%20Метод%20малого%20параметра%20Пуанкаре.ipynb)
*   **Теория:** Проблема вековых членов при прямом разложении по Тейлору. Метод Линдштедта-Пуанкаре.
*   **Практика:** Расчет нелинейного сдвига частоты ангармонического осциллятора Дюффинга до второго порядка малости $O(\varepsilon^2)$.
*   **Приложения:** Связь метода Пуанкаре со статьей Д. Ричардсона (1980) о построении трехмерных периодических гало-орбит в окретсности точек Лагранжа $L_1/L_2$.

### [B.2.  Метод Ван-дер-Поля и малые возмущения в консервативных системах](./Asymtotic%20Methods%20in%20Astrodynamics/B.2%20Метод%20Ван-дер-Поля%20и%20малые%20возмущения%20в%20консервативных%20системах.ipynb)
*   **Теория:** Построение семейства решений порождающего уравнения консервативных нелинейных систем. Инвариантность определителя канонического преобразования $\Delta$ относительно быстрой фазы. Связь интеграла энергии $H$ с периодом колебаний.
*   **Практика:** Символьное доказательство тождества $\Delta_{\varphi} \equiv 0$ и численное верификационное моделирование на сохранение полной энергии системы.

### [B.3. Релаксационные колебания в осцилляторе Ван-дер-Поля](./Asymtotic%20Methods%20in%20Astrodynamics/B.3%20Релаксационные%20колебания%20в%20осцилляторе%20Ван-дер-Поля.ipynb)
*   **Теория:** Метод медленно меняющихся амплитуд (метод усреднения Ван-дер-Поля). Квазилинейные системы и критерии устойчивости предельных циклов. Динамика сильно нелинейных систем при малом параметре при старшей производной (сингулярные возмущения).
*   **Практика:** Построение фазовых портретов, моделирование быстрых и медленных участков (сшивка траекторий) и расчет фактического периода колебаний.

### [B.4. Метод фон Цейпеля](./Asymtotic%20Methods%20in%20Astrodynamics/B.4%20Метод%20фон%20Цейпеля.ipynb)
*   **Теория:** Метод неявных канонических преобразований в переменных «действие-угол» Делоне. Использование смешанных производящих функций $S(\bar{I}, \theta)$ для последовательного исключения коротко- и долгопериодических гармоник.
*   **Практика:** Построение инварианта первого порядка малости для нелинейного гамильтониана.
*   **Приложения:** Усреднение Брауэра (1959) в теории движения ИСЗ. Моделирование векового дрейфа долготы восходящего узла $\Omega(t)$ спутника под действием полярного сжатия Земли (гармоника геопотенциала $J_2$).

### [B.5. Метод преобразований Ли](./Asymtotic%20Methods%20in%20Astrodynamics/B.5%20Метод%20преобразований%20Ли.ipynb)
*   **Теория:** Современный явный аппарат теории возмущений гамильтоновых систем. Экспоненциальный оператор Ли $\exp(\varepsilon L_W)$ и генераторы Ли (функции Депри). Рекуррентная алгебраическая схема Хори-Депри на основе скобок Пуассона.
*   **Практика:** Автоматическое вычисление генераторов $W_k$ и эффективных гамильтонианов $\bar{H}_k$ высших порядков малости на языке Python с помощью библиотеки `SymPy`.
*   **Приложения:** Реализация концепции «радикального упрощения» Депри для долгосрочного прогнозирования элементов орбит космических аппаратов. Прямое выпрямление мгновенного пульсирующего эксцентриситета орбиты ИСЗ в гладкий канонический инвариант.
