## 🗺️ Содержание курса и структура ноутбуков

### [0. Метод малого параметра Пуанкаре](./Spring%20Term/0%20Метод%20малого%20параметра%20Пуанкаре.ipynb)
*   **Теория:** Проблема вековых членов при прямом разложении по Тейлору. Метод деформации времени Линдштедта-Пуанкаре. Условие отсутствия векового разлета траекторий.
*   **Практика:** Расчет нелинейного сдвига частоты ангармонического осциллятора Дуффинга до второго порядка малости $O(\varepsilon^2)$.
*   **Приложения:** Связь метода Пуанкаре со статьей Д. Ричардсона (1980) о построении трехмерных периодических гало-орбит (Halo orbits) около точек Лагранжа $L_1/L_2$.

### [1. Малые возмущения и колебания в консервативных системах](./Spring%20Term/1%20Малые%20возмущения%20и%20колебания%20в%20консервативных%20системах.ipynb)
*   **Теория:** Построение семейства решений порождающего уравнения консервативных нелинейных систем. Инвариантность определителя канонического преобразования $\Delta$ относительно быстрой фазы. Связь интеграла энергии $H$ с периодом колебаний.
*   **Практика:** Символьное доказательство тождества $\Delta_{\varphi} \equiv 0$ и численное верификационное моделирование на сохранение полной энергии системы.

### [2. Релаксационные колебания в осцилляторе Ван-дер-Поля](./Spring%20Term/2%20Релаксационные%20колебания%20в%20осцилляторе%20Ван-дер-Поля.ipynb)
*   **Теория:** Метод медленно меняющихся амплитуд (метод усреднения Ван-дер-Поля). Квазилинейные системы и критерии устойчивости предельных циклов. Теоремы усреднения Боголюбова. Динамика сильно нелинейных систем при малом параметре при старшей производной (сингулярные возмущения).
*   **Практика:** Построение фазовых портретов, моделирование быстрых и медленных участков (сшивка траекторий) и расчет фактического периода колебаний.
*   **Приложения:** Модель релаксационного сердца Ван дер Поля — Ван дер Марка (1928) и модель мембраны нейрона ФитцХью — Нагумо (1961).

### [3. Метод фон Цейпеля](./Spring%20Term/3%20Метод%20фон%20Цейпеля.ipynb)
*   **Теория:** Метод неявных канонических преобразований в переменных «действие — угол» Делоне. Использование смешанных производящих функций $S(\bar{I}, \theta)$ для последовательного исключения коротко- и долгопериодических гармоник.
*   **Практика:** Построение стабильного инварианта первого порядка малости для нелинейного гамильтониана.
*   **Приложения:** Усреднение Дирка Брауэра (1959) в теории движения ИСЗ. Моделирование векового дрейфа долготы восходящего узла $\Omega(t)$ спутника под действием полярного сжатия Земли (геопотенциальная гармоника $J_2$).

### [4. Метод генераторов Ли](./Spring%20Term/4%20Метод%20генераторов%20Ли.ipynb)
*   **Теория:** Современный явный аппарат теории возмущений гамильтоновых систем. Экспоненциальный оператор Ли $\exp(\varepsilon L_W)$ и генераторы Ли (функции Депри). Рекуррентная алгебраическая схема Хори — Депри на основе скобок Пуассона.
*   **Практика:** Автоматическое вычисление генераторов $W_k$ и эффективных гамильтонианов $\bar{H}_k$ высших порядков малости на языке Python с помощью библиотеки `SymPy`.
*   **Приложения:** Реализация концепции «радикального упрощения» Депри для долгосрочного прогнозирования элементов орбит космических аппаратов. Прямое выпрямление мгновенного пульсирующего эксцентриситета орбиты ИСЗ в гладкий канонический инвариант.
